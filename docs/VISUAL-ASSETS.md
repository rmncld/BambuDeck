## Version and validation boundaries

- The public presentation version is **1.3.0**; the local manifest uses **1.3.0.0**.
- The Elgato Marketplace product page listed **1.2.5** on 21 October 2026. The README does not claim Marketplace approval for 1.3.0.
- Camera validation on real hardware covers **P1S**. Other camera model implementations are experimental and are not promoted as hardware-validated compatibility.
- BambuBuddy has software verification; physical Stream Deck appearance and perceived animation smoothness remain to be checked by the user.
- Local release notes and test reports were inspected for scope. Tests were not rerun as part of this documentation-only update.
- The two unreferenced v1.2 images (`v12-feature-grid.jpg`, `v12-local-setup.jpg`) were inspected and left out of the README because of their limited image quality.

No plugin source, installer, manifest, firmware command or Marketplace release is changed by this presentation update.
