# Setup and configuration

BambuDeck is configured from the Property Inspector built into the Stream Deck software.

## Configuration sections

### Device

The user selects the printer profile and target device used by the action.

### Network

Local connection information is entered for the selected printer. Public screenshots intentionally leave these values blank.

### Access

The printer access value required for local authentication is entered separately from the network settings. It must never be included in screenshots, logs, examples or public repository files.

## Readiness state

The setup header exposes a visible state so the user can distinguish a usable configuration from missing connection information. The demonstrated interface displays **READY** once the required setup is available.

## Physical layout

Actions can be arranged freely on the Stream Deck canvas. Empty keys in the demonstrated 5 × 3 profile are deliberate spacing choices, not missing data or failed actions.

## Public-media rule

Any public configuration image must hide:

- printer access codes;
- local addresses and ports;
- authentication values;
- other private network information.
