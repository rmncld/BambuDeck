# Roadmap

## Stage 1 — Working prototype

- Local P1S connectivity
- Live printer telemetry
- Dynamic physical-key interface
- AMS colors and active tray
- Chamber-light toggle
- Real-hardware demonstration

## Stage 2 — Public presentation

- Professional project page
- Square project visuals
- Edited demonstration video
- Compatibility statement
- Marketplace presentation material

## Stage 3 — Release validation

- Installation and configuration flow
- Error-state testing
- Long-running connection tests
- Packaging and versioning
- Final public feature scope

## Stage 4 — Expansion

- Additional hardware profiles after testing
- Alternative Stream Deck layouts
- Multi-printer design
- Detailed AMS tray pages
- Filament color and material metadata
- AMS humidity and temperature monitoring
- Multi-AMS navigation
- File, layer and extended job information
- Carefully validated optional controls

Roadmap items are intentions, not promises of availability.
